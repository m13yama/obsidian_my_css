Source mode now uses the full editor pane, with source text and line numbers aligned to the left. Configure the new options under **Settings → Obsidian My CSS → Source editor**.

- Choose wrapping at the editor's right edge or horizontal scrolling without wrapping.
- Show source-only line numbers that stay visible while scrolling horizontally; click a number to select its line.
- Enable column rulers at positions such as `80, 120`. Rulers follow horizontal scrolling and the current source font after mode changes.
- Use a monospace font with uniform heading sizes and optional current-line highlighting.
- Toggle wrapping and rulers from the command palette or assign hotkeys.

The source layout, line numbers, monospace font, current-line highlighting, and wrapping are enabled by default. Rulers are initially off. Disable **Enable source editor layout** to restore the previous source layout. Reading view and Live Preview retain their existing behavior.
