Reading view now has a fixed table of contents on the right, styled with the existing note font and theme colors. Enable or disable it under **Settings → Obsidian My CSS → Reading view → Show table of contents** (on by default).

- Initially show only top-level headings; use the arrows to expand and collapse subsections.
- Click a heading to jump to its location, including off-screen headings and headings with repeated names.
- Hide the contents to reclaim space, and restore them with the contents button. The visibility preference and feature setting persist across restarts.
- Emphasize the current section, or its visible ancestor when the subsection is collapsed.
- Keep navigation available while scrolling; in narrow panes, open a compact panel that closes after selecting a heading or pressing Escape.
- Refresh the contents when headings change and maintain a separate outline for each Reading view pane.

Notes without headings have no contents panel. Live Preview, Source mode, embedded notes, and print output keep their existing layout. Markdown files are not modified by contents navigation.

Validation: automated tests in a disposable Obsidian vault cover contents hierarchy, keyboard controls, duplicate-heading navigation, live updates, split and narrow panes, settings persistence, mode switching, and plugin unload/reload, alongside the existing source editor tests. Light and dark layouts, JavaScript syntax, release version consistency, and Git whitespace checks were also verified.

Update through BRAT, or install the attached `manifest.json`, `main.js`, and `styles.css` files.
