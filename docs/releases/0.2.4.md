Note headings and common components now take their cues from [matcha.css](https://github.com/lowlighter/matcha), adapted to Obsidian's theme colors and font size.

- H1–H6 use a bold, six-level size hierarchy, with thin H1/H2 dividers and muted H6 text. All headings use the note font, including Japanese text.
- Quotes, horizontal rules, code and image corners, disclosure panels, keyboard hints, and links have a consistent appearance in Reading view and Live Preview.
- Tables have shaded headers and alternating row backgrounds while retaining their original cell padding, alignment, caption placement, and Live Preview editing controls.

Compact body spacing, pink inline code, centered images and tables, source editor tools, and Mermaid zoom are preserved. Styles are bundled locally with no CDN dependency.

Validation: the automated Obsidian smoke test, JavaScript syntax check, and Git whitespace check passed. Table geometry was compared against the previous release in light and dark modes, Reading view and Live Preview, at wide and narrow pane sizes. Live table editing was also checked.

Update through BRAT, or install the attached `manifest.json`, `main.js`, and `styles.css` files.
