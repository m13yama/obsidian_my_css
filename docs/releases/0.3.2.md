The core Bookmarks button now stays visible at the top right of Markdown notes, including notes that are not bookmarked yet. Click it to add or remove a bookmark through Obsidian's standard dialog.

- Works in Reading view, Live Preview, and Source mode, including split panes and collapsed sidebars.
- Uses the existing core button and native bookmark storage.
- Requires the **Bookmarks** core plugin and **Settings → Appearance → Show tab title bar** to be enabled.

Validation: checked adding and removing bookmarks in all three modes, light and dark themes, split panes, native persistence, and restoration of normal button visibility when My CSS is disabled in a disposable Obsidian vault. Existing source editor and Reading view table of contents tests also passed.

Update through BRAT, or install the attached `manifest.json`, `main.js`, and `styles.css` files.
