Mermaid diagram sizing and the zoom viewer have moved into the independent [My Mermaid plugin](https://github.com/m13yama/obsidian_my_mermaid). My CSS now focuses on note styling, bookmarks, the Reading view table of contents, and source editor layout.

To keep Mermaid zoom and use the new `mermaid|500` or `mermaid|800x500` size notation, add `m13yama/obsidian_my_mermaid` through BRAT and enable **My Mermaid**. It provides a viewer that fills the application window, zoom controls, and per-diagram sizes in Reading view and Live Preview.

This release removes Mermaid-specific JavaScript and CSS from My CSS. It does not change note contents or saved My CSS settings.

Validation: source editor and Reading view table of contents smoke tests in a disposable Obsidian vault. The test harness also supports the newer separate Settings window.

Update through BRAT, or install the attached `manifest.json`, `main.js`, and `styles.css` files.
